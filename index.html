Connect Apple Health

A one-time setup in the Shortcuts app, about two minutes.

  1. Open Shortcuts and tap + to make a new shortcut.
  2. Name it exactly Log Mindful Minutes.
  3. Add the action Get Numbers from Input (input: Shortcut Input).
  4. Add Log Health Sample. Set Type to Mindful Minutes.
  5. Set the duration / value to Numbers (minutes). If it asks for Start and End dates instead, set End to Current Date and Start to an Adjust Date action that subtracts Numbers minutes from Current Date.
  6. Tap the shortcut’s ⓘ and turn off Show When Run if offered. Run it once to grant Health access.

After each session, tap Save to Apple Health. Shortcuts opens for a moment, logs the minutes, and you can swipe back.
